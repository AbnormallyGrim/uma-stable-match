# Runner sprite

`runner.webp` is the sprite strip for the search progress bar's running silhouette: a gold silhouette of a running horse girl, facing right.

## Layout

- 8 frames side by side, each 139 × 96 pixels, so the strip is 1112 × 96.
- One flat colour, `#b09551`, on a transparent background.
- Cropped to a shared box, so the figure doesn't shift between frames.
- Frames play in order at 50 ms each, 20 frames per second, looping.
- The first frame is the still pose for visitors who prefer reduced motion.
- The file carries no metadata.
